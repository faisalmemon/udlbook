\section{Equivariance and invariance}

If $\mathbf{P}$ is a permutation matrix, then the following holds:
\begin{equation*}
    \mathbf{H}_{k+1}\mathbf{P} = \mathbf{F}[\mathbf{H}_{k}\mathbf{P}, \mathbf{P}^{T}\mathbf{A}\mathbf{\mathbf{P}}, \boldsymbol{\phi}_{k}].
\end{equation*}
